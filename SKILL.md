# State Snapshot Checkpoint Resumer

## Description
Cryptographically verified checkpoint snapshot manager saving agent execution memory, tool states, and resuming without drift.

## Compatibility
- MCP Version: 2025-12-11
- Python: >=3.10 (Standard Library only)
- Supported Platforms: Claude Desktop, Cursor, LobeChat, Smithery
